# Go_Mini_Projects

## Commands

- build: `go build ./...`
- test: `go test ./...`

## Layout

- `Books_Managment_Mysql/`
- `CRUD_API/`
- `email-dispacher/`
- `go-postgres-stockapi/`
- `jwt-project/`
- `slackbot_fileupload/`
- `web_server_go/`

## Rules

- Run `go test ./...` before you say a change is done.
- Never commit secrets or `.env` files.
